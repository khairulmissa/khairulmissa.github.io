# khairulmissa.github.io

My personal portfolio: projects, skills, experience and contact.

**Live:** https://khairulmissa.github.io

Built with plain HTML, CSS and JavaScript. No framework, no build step. Hosted on GitHub Pages.

## Pages

- `index.html`: home (hero, projects, skills, experience, about, contact)
- `talkiepal.html`: TalkiePal case study
- `404.html`: page not found

## Run locally

Open the folder in VS Code and use **Live Server** (right click `index.html` → Open with Live Server).
